## 💡 KEY DECISIONS MADE

### Technology Stack
- **Backend**: Flask + PostgreSQL + SQLAlchemy
- **Frontend**: React 18 + Redux + Tailwind CSS
- **Auth**: JWT (stateless, scalable)
- **Hashing**: Bcrypt (industry standard)
- **API Client**: Axios with interceptors

### Architecture Patterns
- **Backend**: MVC pattern with service layer
- **Frontend**: Redux + React Router + Component-based
- **Auth**: JWT with refresh token rotation
- **State**: Redux Toolkit for predictable state
- **Styling**: Utility-first with Tailwind

### Security Choices
- ✅ Bcrypt with 12 rounds (resistant to GPU attacks)
- ✅ Separate access/refresh tokens (attack surface reduction)
- ✅ HTTPS-ready configuration
- ✅ SQL injection prevention (ORM)
- ✅ CORS with restricted origins
